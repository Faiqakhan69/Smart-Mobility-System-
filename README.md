# Smart-Mobility-System-

## Overview
A Smart Mobility Assistance System developed to help visually impaired individuals navigate their surroundings more safely.

## Key Features
- Obstacle Detection and Avoidance
- Bluetooth Connectivity
- Android Voice Control
- Automatic Navigation Mode
- Parking Slot Detection
- 
## Technologies & Hardware
- Arduino Uno
- Ultrasonic Sensors
- IR Sensors
- Bluetooth Module
- L293D Motor Driver
- Servo Motor
- Android Application

## My Contribution
Worked on system development, hardware integration, sensor interfacing, and project functionality.

## Project Purpose
To provide an assistive mobility solution that improves navigation and independence for visually impaired individuals.
